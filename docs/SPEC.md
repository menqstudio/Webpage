# Menq — Business Landing Page · SPEC

> ԱԲ, ավտոմատացում և ծրագրային լուծումներ բիզնեսի աճի համար։

Սա ապրանքի/էջի ամբողջական պահանջների փաստաթուղթն ա (single source of truth)։
Կոդը գրվում ա սրա հիման վրա։

---

## 0. Ո՞վ ենք / Ի՞նչ ենք վաճառում

Մենք բիզնեսի համար ստեղծում ենք **ԱԲ-ով ուժեղացված ծրագրային լուծումներ, ավտոմատացումներ
և թվային համակարգեր**, որոնք **կրճատում են ծախսերը, խնայում ժամանակը ու բերում նոր հաճախորդներ**։

Էջը վաճառում ա **ոչ թե «ծրագրավորում», այլ բիզնես արդյունք**։

- ❌ «Մենք սարքում ենք CRM, կայք, dashboard»
- ✅ «Մենք կառուցում ենք համակարգեր, որոնք օգնում են բիզնեսին ավելի շատ վաճառել,
  ավելի քիչ ծախսել, արագ աշխատել և վերահսկել ամբողջ գործընթացը»։

---

## 1. Էջի նպատակը

Գլխավոր նպատակը՝ **նոր հաճախորդ ներգրավել (lead generation)**։

Visitor-ը 10–20 վայրկյանում պետք ա հասկանա.

1. Դուք ինչ եք անում։
2. Իր բիզնեսը ինչ օգուտ կստանա։
3. Ինչ տեսակի լուծումներ եք առաջարկում։
4. Ինչու կարելի ա վստահել ձեզ։
5. Ինչ քայլ պետք ա անի հիմա (CTA)։

---

## 2. Դիրքավորում (positioning)

**ԱԲ, ավտոմատացում և ծրագրային լուծումներ բիզնեսի աճի համար**

Մենք օգնում ենք բիզնեսներին կրճատել ծախսերը, խնայել ժամանակը, ներգրավել նոր հաճախորդներ
և ստեղծել վերահսկելի աշխատանքային համակարգեր՝ ԱԲ-ի, ավտոմատացման և անհատական
ծրագրային լուծումների միջոցով։

Կառուցում ենք CRM համակարգեր, web կայքեր, landing page-եր, ներքին կառավարման հարթակներ,
dashboard-ներ, workflow automation-ներ և AI-powered լուծումներ։

## 4. Sections — բովանդակություն

### 1) Header / Navigation
- Մաքուր, premium, վստահություն տվող։ Sticky, բայց ոչ ծանր։
- Ձախ՝ **Logo**։ Աջ՝ navigation։
- Menu: Գլխավոր · Լուծումներ · Ոլորտներ · Ինչպես ենք աշխատում · Սերտիֆիկացումներ · Կապ
- CTA button: **Ստանալ խորհրդատվություն**

### 2) Hero
**Վերնագիր (վերջնական տարբերակ):**
> Բիզնեսի հաջողության բանալին՝ ԱԲ, ավտոմատացում և խելացի ծրագրային լուծումներ

**Subtext:**
> Մենք օգնում ենք բիզնեսներին կրճատել ծախսերը, խնայել ժամանակը, ներգրավել նոր հաճախորդներ
> և աշխատել ավելի վերահսկելի՝ CRM համակարգերի, web կայքերի, dashboard-ների, ներքին հարթակների
> և ԱԲ-ով աշխատող ավտոմատացումների միջոցով։
>
> Ձեր բիզնեսում գտնում ենք այն կետերը, որտեղ կորում են ժամանակ, գումար և վերահսկողություն,
> հետո դրանք փոխարինում ենք արագ, չափելի և ավտոմատացված համակարգերով։

**CTA-ներ:** `Ստանալ անվճար խորհրդատվություն` · `Տեսնել լուծումները`

**Trust line (CTA-ի տակ):**
> Պաշտոնապես սերտիֆիկացված մասնագետներ · ԱԲ լուծումներ · CRM · Web · Automation · Dashboard · Business Systems

**Visual (աջ):** abstract dashboard / workflow տեսարան — CRM, AI, Website, Dashboard,
Automation, Analytics հանգույցները միացված իրար։

### 3) Pain — «Որտե՞ղ է բիզնեսը կորցնում գումար»
**Վերնագիր:** Բիզնեսը գումար է կորցնում, երբ գործընթացները համակարգված չեն

**Text:** Շատ բիզնեսներ չեն կորցնում գումար միայն վատ վաճառքի պատճառով։ Հաճախ իրական կորուստը
գալիս է չկարգավորված գործընթացներից, ձեռքի աշխատանքից, ուշացումներից, սխալներից և վերահսկելիության պակասից։

**Cards (6):**
1. **Ձեռքի կրկնվող աշխատանք** — copy-paste, հաշվարկ, follow-up, status update, ֆայլերի լրացում։
2. **Ցրված տվյալներ** — Excel, չատեր, email, CRM — բայց ոչ մեկ տեղում։
3. **Վաճառքի կորած հնարավորություններ** — lead-երը ուշ են մշակվում, follow-up-ները մոռացվում են։
4. **Թույլ վերահսկողություն** — ղեկավարությունը real-time չի տեսնում bottleneck-ը։
5. **Ավելորդ ծախսեր** — ժամանակի կորուստ, սխալներ, ուշացումներ → թաքնված ծախսեր։
6. **Կախվածություն մարդկանցից** — գործընթացը մարդու հիշողության մեջ ա, ոչ համակարգում։

**Փակող տող:** Եթե գործընթացը չի չափվում, այն չի կառավարվում։ Եթե չի ավտոմատացվում, այն սկսում է թանկ նստել բիզնեսի վրա։

### 4) Solution Overview — «Ինչ ենք մենք անում»
**Վերնագիր:** Մենք ստեղծում ենք թվային համակարգեր, որոնք բիզնեսը դարձնում են արագ, վերահսկելի և scalable

**Text:** Մենք չենք առաջարկում միայն կայք կամ միայն ծրագիր։ Ուսումնասիրում ենք բիզնեսի իրական
աշխատանքային հոսքերը և կառուցում ենք լուծումներ կոնկրետ խնդրի համար՝ վաճառք, սպասարկում,
կառավարում, հաշվետվություն, ավտոմատացում, վերահսկողություն կամ հաճախորդների ներգրավում։

**Cards (6):**
1. **Ծրագրային լուծումներ** — CRM, ներքին հարթակներ, dashboard-ներ, web apps, management tools։
2. **ԱԲ ավտոմատացում** — AI assistants, data analysis, document processing, smart routing, recommendations, automated decisions։
3. **Web և online ներկայություն** — կորպորատիվ կայքեր, landing page-եր, lead gen էջեր, online forms, service pages։
4. **Business process automation** — workflow-ներ, approval logic, task routing, SLA control, notifications, escalation rules։
5. **Համակարգերի ինտեգրացիա** — CRM, website, accounting, warehouse, email, Telegram/WhatsApp, payment, Google tools։
6. **Analytics և կառավարում** — CEO dashboard, KPI tracking, sales reports, operational visibility, cost control, performance analytics։

### 5) Services — «Մեր լուծումները» (service core)
1. **CRM համակարգեր** — հաճախորդների բազա, lead management, վաճառքի փուլեր, follow-up automation,
   task/հիշեցումներ, pipeline, report-ներ, manager view։
   _Value:_ ավելի քիչ կորած lead, ավելի արագ վաճառք, ավելի վերահսկելի sales team։
2. **Web կայքեր և landing page-եր** — կորպորատիվ կայք, ծառայությունների էջեր, lead gen landing,
   կապի form-եր, online հայտեր, SEO-friendly կառուցվածք, responsive design։
   _Value:_ ավելի վստահելի բրենդ, ավելի շատ դիմումներ, ուժեղ online ներկայություն։
3. **Ներքին կառավարման համակարգեր** — պատվերների կառավարում, task management, հայտերի կառավարում,
   բաժինների workflow-ներ, approval flow, status tracking, role-based access։
   _Value:_ քիչ քաոս, հստակ պատասխանատվություն, արագ ընթացք։
4. **Dashboard-ներ և analytics** — CEO/sales/finance/operations dashboard, KPI tracking, real-time status,
   ուշացումների/ռիսկերի տեսանելիություն։
   _Value:_ որոշումներ ոչ թե զգացողությամբ, այլ թվերով։
5. **ԱԲ ավտոմատացումներ** — AI assistant-ներ, document analysis, request classification,
   smart response suggestions, data extraction, automated recommendations, anomaly detection։
   _Value:_ քիչ ձեռքի աշխատանք, արագ մշակում, խելացի որոշումներ։
6. **Workflow automation** — փուլեր, պատասխանատուներ, deadline, reminder, escalation, approval logic, auto status changes։
   _Value:_ գործը չի կորում, չի մոռացվում, չի կանգնում անհասկանալի տեղում։
7. **Համակարգերի ինտեգրացիա** — CRM, website forms, accounting, warehouse, payment, email,
   Telegram/WhatsApp, Google Sheets/Drive/Calendar։
   _Value:_ տվյալները չեն կրկնվում ձեռքով, համակարգերը աշխատում են իրար հետ։

### 6) Business Success Key (գաղափարական սիրտ)
**Վերնագիր:** Բիզնեսի հաջողության բանալին համակարգված աշխատանքն է

**Text:** Բիզնեսը աճում է ոչ միայն լավ ապրանքով կամ թիմով, այլ երբ ունի ճիշտ կառուցված համակարգեր։
Երբ վաճառքը, սպասարկումը, ֆինանսները, պահեստը, task-երը և ղեկավարումը աշխատում են առանձին,
բիզնեսը կորցնում է արագություն։ Երբ միանում են մեկ համակարգի մեջ՝ դառնում է կառավարելի։
Մենք օգնում ենք անել այդ անցումը՝ ձեռքի/ցրված աշխատանքից → թվային, ավտոմատացված, չափելի համակարգ։

**6 point:**
- Ամեն գործողություն ունի պատասխանատու։
- Ամեն փուլ ունի կարգավիճակ։
- Ամեն ուշացում տեսանելի է։
- Ամեն կրկնվող քայլ կարող է ավտոմատացվել։
- Ամեն որոշում կարող է հիմնվել տվյալների վրա։
- Ամեն ղեկավար կարող է տեսնել իրական վիճակը մեկ էկրանում։

**Փակող տող:** Արդյունքը՝ ավելի քիչ քաոս, ավելի քիչ ծախս, ավելի արագ թիմ և ավելի ուժեղ կառավարում։

### 8) Results — «Ինչ է ստանում հաճախորդը» (շատ վաճառող)
**Cards (6):**
1. **Ծախսերի կրճատում** — քիչ ձեռքի աշխատանք, քիչ սխալներ, քիչ ուշացում, քիչ կորած ռեսուրս։
2. **Ժամանակի խնայողություն** — կրկնվող գործողությունները ավտոմատ/կիսաավտոմատ, թիմը կարևորի վրա։
3. **Նոր հաճախորդների ներգրավում** — վաճառող կայքեր, landing, CRM + follow-up automation։
4. **Վերահսկելի աշխատանք** — ով ինչ է անում, որ փուլում է գործը, որտեղ է խնդիրը։
5. **Ավելի քիչ սխալներ** — քիչ կրկնակի մուտքագրում, քիչ մոռացված task, քիչ սխալ հաշվարկ։
6. **Աճի պատրաստ համակարգ** — բիզնեսը մեծանում է առանց քաոսը մեծացնելու։

### 9) AI as Business Tool — «Ինչու ԱԲ»
**Վերնագիր:** ԱԲ-ն օգտագործում ենք որպես բիզնես գործիք, ոչ թե որպես մոդայիկ բառ

**Text:** ԱԲ-ն կարող է վերլուծել տվյալներ, դասակարգել հարցումներ, առաջարկել հաջորդ քայլեր,
մշակել փաստաթղթեր, հայտնաբերել pattern-ներ և արագացնել թիմի աշխատանքը։
Օգտագործում ենք այնտեղ, որտեղ տալիս է իրական արդյունք՝ խնայված ժամանակ, կրճատված ծախս,
արագացված աշխատանք, ավելի լավ վերահսկողություն։

**AI capabilities:** data analysis · document processing · customer request classification ·
smart recommendations · workflow decision support · automated reporting · anomaly detection · internal AI assistants

### 10) How We Work (stepper, 6)
1. **Բիզնեսի վերլուծություն** — ընթացիկ հոսքեր, խնդիրներ, կրկնվող քայլեր, ծախսատար հատվածներ։
2. **Լուծման քարտեզագրում** — որտեղ կայք, որտեղ CRM, որտեղ dashboard, որտեղ automation, որտեղ ԱԲ։
3. **Նախագծում** — էջեր, ֆունկցիաներ, workflow, role, տվյալներ, integration։
4. **Կառուցում** — կայք/CRM/dashboard/automation կամ ամբողջական համակարգ։
5. **Ներդրում** — կարգավորում, գործիքների կապ, թիմին փոխանցում, օգտագործման օգնություն։
6. **Չափում և բարելավում** — ժամանակի խնայողություն, ծախսերի կրճատում, արագություն, վերահսկելիություն։

### 11) Certifications / Trust
**Վերնագիր:** Պաշտոնապես սերտիֆիկացված մասնագետներ

**Text:** Մեր թիմը ունի պաշտոնական սերտիֆիկացումներ ԱԲ գործիքների, ավտոմատացման և
թվային լուծումների ուղղություններով։ Աշխատում ենք պրոֆեսիոնալ մոտեցմամբ՝ հասկանալով
ոչ միայն տեխնոլոգիան, այլ նաև բիզնեսի իրական նպատակը։

### 12) Example Problems We Solve
**Վերնագիր:** Օրինակ խնդիրներ, որոնք կարող ենք լուծել

**Cards (6) — problem → solution:**

2. «Աշխատակիցները ամեն օր նույն հաշվետվությունն են հավաքում» → data integration + automated dashboard։
3. «Ղեկավարը չի տեսնում իրական վիճակը» → management dashboard + KPI tracking։
4. «Պատվերները ուշանում են, պատճառը պարզ չէ» → workflow automation + SLA + escalation։
5. «Հաճախորդների սպասարկումը խառն է» → ticket system + priority rules + customer history։
6. «Շատ աշխատանք արվում է Excel-ով ու չատերով» → internal management system + role-based workspaces։

## 5. Design direction

Premium **tech-business** ոճ։ Ոչ շատ գունավոր, ոչ խաղալիք, ոչ template-ի նման։

**Visual style:**
- Dark navy / charcoal ֆոն որոշ section-ներում, white/light մնացածում (alternating)։
- Մեկ ուժեղ accent color՝ electric blue / cyan / violet / green (ընտրելու ենք)։
- Շատ card-եր, շատ spacing, մաքուր typography։
- Dashboard-style visual elements, AI network / workflow գծեր, business metrics cards։

**UI components:** Hero badge · CTA buttons · Service cards · Problem cards · Result cards ·
Stepper · Certificate badges · Lead form · Dashboard mockup visual · Integration icons · Workflow diagram
