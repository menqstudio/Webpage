# Menq — Section-by-Section Wireframe

Ամեն section՝ ի՞նչ ա երևում էկրանին, ձախ/աջ ի՞նչ կա, cards / text+visual / form։
Desktop layout (mobile-ի համար ամեն ինչ stack ա լինում մեկ սյունով)։

Legend: `▢` card · `●` icon · `[CTA]` button · `____` input

---

## 1) HEADER — sticky nav
```
┌──────────────────────────────────────────────────────────────────────┐
│  ● Menq        Գլխավոր  Լուծումներ  Ոլորտներ  Ինչպես  Սերտիֆ.  Կապ   [Ստանալ խորհրդատվություն] │
└──────────────────────────────────────────────────────────────────────┘
```
- Ձախ՝ logo։ Կենտրոն/աջ՝ nav links։ Ծայր աջ՝ accent CTA button։
- Sticky, scroll-ի վրա մի քիչ blur/բարակ border (թեթև)։ Mobile՝ hamburger։

## 2) HERO — text (ձախ) + visual (աջ)
```
┌─────────────────────────────────┬──────────────────────────────────┐
│  ◦ badge: Սերտիֆիկացված մասնագ.  │                                  │
│                                  │     ┌─ Dashboard / workflow ─┐    │
│  H1: Բիզնեսի հաջողության         │     │  CRM ─── AI ─── Web     │    │
│      բանալին՝ ԱԲ, ավտոմատացում   │     │   │      │      │       │    │
│      և խելացի ծրագրային լուծ.    │     │  Dashboard ─ Automation │    │
│                                  │     │   Analytics (metrics)   │    │
│  P: subtext (2 պարբ.)            │     └─────────────────────────┘    │
│                                  │     (animated nodes/lines)        │
│  [Անվճար խորհրդատվություն] [Տեսնել լուծումները]                       │
│  trust line · CRM · Web · AI · Automation · Dashboard                │
└─────────────────────────────────┴──────────────────────────────────┘
```
- **Dark navy ֆոն**, accent glow։ Ձախ՝ copy + 2 CTA + trust line։ Աջ՝ abstract animated dashboard/network։

## 3) PAIN — «Որտեղ է բիզնեսը կորցնում գումար» — 6 cards (3×2)
```
        H2 (center): Բիզնեսը գումար է կորցնում, երբ գործընթացները համակարգված չեն
        P (center, narrow): intro text
┌───────────────┐ ┌───────────────┐ ┌───────────────┐
│ ● Ձեռքի կրկնվ. │ │ ● Ցրված տվյալ.│ │ ● Կորած lead  │
└───────────────┘ └───────────────┘ └───────────────┘
┌───────────────┐ ┌───────────────┐ ┌───────────────┐
│ ● Թույլ վերահ. │ │ ● Ավելորդ ծախ.│ │ ● Կախվածությ. │
└───────────────┘ └───────────────┘ └───────────────┘
        ── փակող տող (highlighted, accent) ──
```
- White/light ֆոն։ Card՝ icon + title + 1-2 տող։ Ներքևում մեկ ուժեղ closing line (accent strip)։

## 4) SOLUTION OVERVIEW — «Ինչ ենք անում» — 6 cards (3×2)
```
        H2 (center) + P (center)
  ▢ Ծրագր. լուծ.   ▢ ԱԲ ավտոմ.     ▢ Web/online
  ▢ Process auto   ▢ Ինտեգրացիա    ▢ Analytics/կառ.
```

- Light/alt ֆոն։ Նույն card grid-ը, ավելի «capability» feel (icon + title + կարճ desc)։

## 5) SERVICES — «Մեր լուծումները» — 7 ընդարձակ card (service core)
```
        H2 (center): Մեր լուծումները
┌──────────────────────────────────────────────────────────────┐
│ 01 ●  CRM համակարգեր                                          │
│       նպատակը + ✓ ներառում (list) + 💡 Business value          │
└──────────────────────────────────────────────────────────────┘
┌──────────────────────────────────────────────────────────────┐
│ 02 ●  Web կայքեր և landing page-եր   ...                       │
└──────────────────────────────────────────────────────────────┘
   ... (03 Ներքին համակ. · 04 Dashboard · 05 ԱԲ · 06 Workflow · 07 Ինտեգրացիա)
```
- Ավելի մեծ, alternating կամ 2-սյունով grid։ Ամեն card՝ number + icon + title + included list (checkmarks) + value line։
- Սա էջի ամենախիտ տեղեկատվական մասն ա → լավ spacing, որ չծանրանա։

## 6) BUSINESS SUCCESS KEY — text (ձախ) + 6 points (աջ)
```
┌──────────────────────────────┬───────────────────────────────┐
│ H2: Բիզնեսի հաջողության       │  ✓ Ամեն գործողություն — պատասխ.│
│     բանալին համակարգված ...   │  ✓ Ամեն փուլ — կարգավիճակ      │
│ P: 2-3 պարբերություն          │  ✓ Ամեն ուշացում — տեսանելի    │
│                              │  ✓ Ամեն կրկնվող քայլ — ավտոմ.  │
│ ── փակող տող (accent) ──      │  ✓ Ամեն որոշում — տվյալներով   │
│                              │  ✓ Ամեն ղեկավար — մեկ էկրան    │
└──────────────────────────────┴───────────────────────────────┘
```
- **Dark navy ֆոն** (գաղափարական սիրտ → ուժեղ visual)։ Ձախ՝ narrative, աջ՝ 6 կարճ checklist point։
