# Admin Architecture / Admin ճարտարապետություն

## Հայերեն
Admin-ը invite-only է։ Core domains՝ users, roles, permissions, leads, bookings, content, services, industries, FAQ, media, audit logs և system events։ Permission checks-ը server-side authority են։ UI visibility-ը security boundary չէ։ Sensitive actions-ը audit trail են պահանջում։

## English
Administration is invite-only. Core domains include users, roles, permissions, leads, bookings, content, services, industries, FAQ, media, audit logs, and system events. Permission checks are server-side authority. UI visibility is not a security boundary. Sensitive actions require an audit trail.
