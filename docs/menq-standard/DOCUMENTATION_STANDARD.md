# Documentation Standard / Փաստաթղթավորման ստանդարտ

## Հայերեն
- Canonical language-ներ՝ Armenian և English, equal meaning։
- Root docs-ը human/AI continuity են։
- `docs/menq-standard/`-ը product governance authority-ն է։
- Legacy/buildpack/must/QA docs-ը preserved evidence են։
- Every canonical write-ը պետք է re-read, validate և synchronize արվի։
- Status, owner, authority և evidence references-ը explicit են։

## English
- Canonical languages are Armenian and English with equal meaning.
- Root documents provide human and AI continuity.
- `docs/menq-standard/` is the product-governance authority.
- Legacy, buildpack, must, and QA documents are preserved evidence.
- Every canonical write must be re-read, validated, and synchronized.
- Status, owner, authority, and evidence references are explicit.
