# Testing and Quality Gates / Testing և quality gates

## Հայերեն
Required gates՝ documentation validator, Design Platform validator, dependency install, lint, typecheck, unit/integration tests, production build և audit artifact։ Runtime-sensitive փոփոխության դեպքում ավելանում են targeted E2E, accessibility, security և rollback checks։ GREEN-ը պահանջում է actual execution evidence։

## English
Required gates are documentation validation, Design Platform validation, dependency installation, lint, typecheck, unit/integration tests, production build, and audit artifact generation. Runtime-sensitive changes add targeted E2E, accessibility, security, and rollback checks. GREEN requires actual execution evidence.
