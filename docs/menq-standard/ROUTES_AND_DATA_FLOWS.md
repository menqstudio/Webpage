# Routes and Data Flows / Routes և data flows

## Հայերեն
Public locale roots՝ `/hy`, `/en`, `/ru`։ Landing page-ը section composition է։ Public API surfaces-ը leads և bookings intake են։ Admin routes-ը content, leads, bookings, users, roles, permissions, audit և settings surfaces են։ Data flow-ը՝ request → validation → authorization/rate-limit → persistence → event/audit/notification → response։

## English
Public locale roots are `/hy`, `/en`, and `/ru`. The landing page is a section composition. Public API surfaces accept leads and bookings. Admin routes cover content, leads, bookings, users, roles, permissions, audit, and settings. Data flow: request → validation → authorization/rate limit → persistence → event/audit/notification → response.
