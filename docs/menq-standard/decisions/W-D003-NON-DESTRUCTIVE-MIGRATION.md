# Non-Destructive Migration / Non-Destructive Migration

**Status / Կարգավիճակ:** Approved / Հաստատված

## Հայերեն
Design migration-ը runtime contract չի փոխում։

## English
The design migration does not change runtime contracts.

## Consequence / Հետևանք
**HY:** Հակասող փոփոխությունը պահանջում է նոր decision transaction։

**EN:** A conflicting change requires a new decision transaction.
