# Release, Operations, and Rollback / Release, operations և rollback

## Հայերեն
Release unit-ը reviewed PR/merge commit է։ Rollback-ը merge commit revert կամ scoped release rollback է։ Database/API format change-ը separate migration plan է պահանջում։ Operational promotion-ը պահանջում է monitoring, owner, support path, incident response և rollback proof։

## English
The release unit is a reviewed PR and merge commit. Rollback uses merge-commit revert or a scoped release rollback. Database or API-format changes require a separate migration plan. Operational promotion requires monitoring, an owner, a support path, incident response, and rollback proof.
