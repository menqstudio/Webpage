# Accessibility, Motion, and Responsive Standard / Accessibility, motion և responsive ստանդարտ

## Հայերեն
Keyboard navigation, visible focus, semantic landmarks/headings, labeled forms, error association, dialog focus management և reduced-motion behavior պարտադիր են։ Mobile/tablet/desktop layouts-ը content priority են պահպանում։ Motion-ը progressive enhancement է, ոչ content access dependency։

## English
Keyboard navigation, visible focus, semantic landmarks and headings, labeled forms, error association, dialog focus management, and reduced-motion behavior are mandatory. Mobile, tablet, and desktop layouts preserve content priority. Motion is progressive enhancement, not a dependency for content access.
