# Content Copy

## Localization rule
The website supports Armenian, English, and Russian. Copy must not mix languages inside the same locale.

- Armenian page: Armenian copy, except unavoidable product names like CRM, ERP, AI if chosen intentionally.
- English page: English copy only.
- Russian page: Russian copy only.

For Armenian, recommended terminology:
- First mention: `ԱԲ / AI`
- After first mention: prefer `ԱԲ` where natural.
- For globally recognized business terms like CRM, ERP, dashboard, use them only if they are more understandable for target clients. Otherwise explain in Armenian.

### Pain section
Title:
Բիզնեսը գումար է կորցնում, երբ գործընթացները համակարգված չեն

Description:
Շատ բիզնեսներ գումար են կորցնում ոչ միայն վաճառքի պակասի պատճառով։ Իրական կորուստը հաճախ գալիս է չկարգավորված գործընթացներից, ձեռքի աշխատանքից, ուշացումներից, սխալներից և վերահսկելիության պակասից։

Pain cards:
1. Ձեռքի կրկնվող աշխատանք
Աշխատակիցները ամեն օր կրկնում են նույն գործողությունները՝ տվյալների մուտքագրում, հաշվարկ, follow-up, status update կամ հաշվետվությունների հավաքում։

2. Ցրված տվյալներ
Տվյալները պահվում են Excel-ներում, չատերում, email-ներում, տարբեր համակարգերում կամ մարդկանց հիշողության մեջ։

3. Կորած վաճառքի հնարավորություններ
Lead-երը չեն մշակվում ժամանակին, follow-up-ները մոռացվում են, իսկ հետաքրքրված հաճախորդները կորչում են փուլերի մեջ։

4. Թույլ վերահսկողություն
Ղեկավարությունը չի տեսնում իրական պահին՝ ով ինչ է անում, որ գործն է ուշանում և որտեղ է առաջացել bottleneck։

5. Ավելորդ ծախսեր
Սխալները, ուշացումները, կրկնվող աշխատանքը և անարդյունավետ գործընթացները դառնում են թաքնված ծախսեր։

6. Կախվածություն մարդկանցից
Գործընթացները պահվում են կոնկրետ աշխատակիցների փորձի կամ հիշողության մեջ, ոչ թե վերահսկելի համակարգում։

Closing callout:
Եթե գործընթացը չի չափվում, այն չի կառավարվում։ Եթե չի ավտոմատացվում, այն սկսում է թանկ նստել բիզնեսի վրա։

### Business success key
Title:

Copy:

Մենք օգնում ենք այդ անցումը անել՝ ձեռքի, ցրված և անկանոն աշխատանքից դեպի թվային, ավտոմատացված և չափելի համակարգ։

Points:
- Ամեն գործողություն ունի պատասխանատու։
- Ամեն փուլ ունի կարգավիճակ։
- Ամեն ուշացում տեսանելի է։
- Ամեն կրկնվող քայլ կարող է ավտոմատացվել։
- Ամեն որոշում կարող է հիմնվել տվյալների վրա։
- Ղեկավարությունը տեսնում է իրական վիճակը մեկ էկրանում։
