# UI Page Structure

## Global layout
- Full-width page.
- Max content container uses layout tokens.
- Alternating dark and light sections.
- Dark hero with premium AI-tech feeling.
- Light sections for service clarity.
- Glass cards used in dark sections.
- Clean solid cards used in light sections.

## Section 1: Header
### Desktop layout
- Height: `--size-header-height`.
- Left: text logo placeholder.
- Center/right: navigation links.
- Right cluster: language switcher, theme switcher, CTA.

### Mobile layout
- Logo left.
- CTA optional short version.
- Menu icon right.
- Full-screen or side drawer navigation.

## Section 2: Hero
### Layout
- Two-column desktop.
- Left: badge, headline, subheadline, CTA row, trust line.
- Right: animated dashboard + AI workflow visual.
- Mobile: stacked, visual below copy.

### Content hierarchy
1. Badge: AI • Automation • Software Solutions
2. H1
3. Supporting text
4. CTA row
5. Trust line

### Visual requirements
- Dashboard cards showing abstract metrics.
- AI workflow nodes connected by glowing lines.
- No real client data.
- All colors from tokens.

## Section 3: Pain / Business Loss
### Layout
- Section heading centered.
- Short explanatory paragraph.
- 6-card grid.
- Closing statement in highlighted callout.

### Card grid
Desktop: 3 columns.
Tablet: 2 columns.
Mobile: 1 column.

## Section 4: Solution Overview
### Layout
- Left copy block.
- Right 2x3 feature card grid or responsive grid.
- Cards represent pillars.

## Section 5: Services
### Layout
- Four large service blocks.
- Each block can be a wide card with internal service chips.
- Desktop: 2x2 grid.
- Mobile: stacked.

### Block anatomy
- Icon badge.
- Title.
- Business goal.
- Included services as chips/list.
- Business value line.

## Section 6: Business Success Key
### Layout
- Dark premium section.
- Large headline.
- Strategic paragraph.
- 6-point system grid.
- Strong closing line.

## Section 7: Industries and Functions
### Layout
- Heading.
- Intro paragraph.
- 5 industry group cards.
- Each card includes examples + recommended solution types.

## Section 8: Results
### Layout
- Light section.
- 6 outcome cards.
- Each card has title, description, icon.

## Section 9: AI as Business Tool
### Layout
- Dark or gradient section.
- Left: explanation copy.
- Right: AI capability matrix.
- Include a non-hype statement: AI is used where it produces business value.

## Section 10: How We Work
### Layout
- Stepper component.
- Desktop: horizontal or vertical timeline depending on viewport.
- Mobile: vertical cards.

Steps:
1. Business analysis.
2. Solution mapping.
3. Design.
4. Build.
5. Implementation.
6. Measurement and improvement.

## Section 11: Why Choose Us / Trust
### Layout
- Heading.
- Trust cards.
- Certification statement without requiring certificate image display.
- Security/privacy mini-block.

## Section 12: FAQ
### Layout
- Accordion.
- Keep answers clear and business-oriented.

## Section 13: Final CTA + Lead Form
### Layout
- Two-column desktop.
- Left: CTA copy and contact alternatives.
- Right: form card.
- Mobile: CTA copy above form.

## Section 14: Footer
### Layout
- Dark footer.
- Logo/slogan.
- Services.
- Contact placeholders.
- Languages.
- Legal placeholders.

## Scroll order rationale
The page first creates urgency, then presents solution, then proves breadth, then builds trust, then converts.
